asmodean
=======

Few-body scattering experiments in an analytical potential: up to 10 softened
bodies of arbitrary masses, integrated in a static potential generated by
`lanfear <https://github.com/alex-rawlings/lanfear>`_, with Gadget softening,
mergers, ejections and optional Chandrasekhar dynamical friction. For
installation see the `README <https://github.com/alex-rawlings/asmodean>`_.

Everything in the API reference is also available directly on the top-level
package, e.g. ``asmodean.BodySystem`` (conventionally imported as
``import asmodean as am``).
